Overview

The InvoiceAI API extracts structured data from invoice text, PDFs, and URLs. Send us raw invoice content and receive a clean JSON object with invoice number, dates, line items, totals, tax, vendor, and client information.

Base URL: https://invoice-parser.up.railway.app

Content Type: All requests and responses use application/json (except file uploads which use multipart/form-data).

Authentication

Pass your API key via the X-Api-Key header: 

X-Api-Key: your-secret-api-key

You can also pass it as a query parameter: ?api_key=your-secret-api-key

Note: The demo endpoint (GET /demo) does not require authentication. In development mode (no API_KEY set), authentication is disabled.

Get your API key by subscribing to the Pro plan.

Endpoints

POST /parse — Parse from Text

POST

Parse invoice data from raw text. The primary endpoint for programmatic use.

POST /parse
Content-Type: application/json
X-Api-Key: your-api-key

{
  "text": "Invoice #: INV-2024-0087\nDate: May 15, 2024\nTotal: $7,376.92\nFrom: Acme Corp\n..."
}

Request Body:

FieldTypeRequiredDescription
textstringYesRaw invoice text content (min 10 characters)
filenamestringNoOptional filename for reference in response

POST /parse/url — Parse from URL

POST

Fetch an invoice from a public URL and parse it. Supports PDF and text files.

POST /parse/url
Content-Type: application/json
X-Api-Key: your-api-key

{
  "url": "https://example.com/invoice.pdf"
}

Request Body:

FieldTypeRequiredDescription
urlstringYesPublic URL to a PDF or text invoice file

POST /parse/file — Parse from Upload

POST

Upload an invoice file directly. Supports PDF, TXT, and CSV formats.

POST /parse/file
Content-Type: multipart/form-data
X-Api-Key: your-api-key

Field: invoice (file)

Request:

FieldTypeRequiredDescription
invoicefileYesFile upload (PDF, TXT). Max 10MB.

GET /demo — Demo Invoice

GET

Returns a pre-parsed demo invoice. No authentication required. Great for testing integration.

GET /demo

GET /health — Health Check

GET

Check if the API is running. Returns server uptime and version.

GET /health

Response Format

All successful responses return a JSON object with the following structure:

{
  "success": true,
  "parsed": {
    "invoiceNumber": "INV-2024-0087",
    "date": "2024-05-15",
    "dueDate": "2024-06-15",
    "vendor": "Acme Software Solutions LLC",
    "billTo": "Johnson & Associates",
    "subtotal": 6799.00,
    "tax": 577.92,
    "taxRate": 8.5,
    "totalAmount": 7376.92,
    "currency": "USD",
    "lineItems": [
      {
        "description": "Web Development Services",
        "quantity": 40,
        "unitPrice": 125.00,
        "lineTotal": 5000.00
      }
    ],
    "confidence": 92,
    "parsedAt": "2026-05-23T10:00:00.000Z"
  }
}

Field Descriptions:

FieldTypeDescription
invoiceNumberstringExtracted invoice or reference number
datestringInvoice date (ISO format YYYY-MM-DD)
dueDatestringPayment due date (ISO format)
vendorstringCompany name of the invoice issuer
billTostringCompany name of the recipient
subtotalnumberSubtotal amount before tax
taxnumberTotal tax amount
taxRatenumberTax rate percentage if detected
totalAmountnumberTotal invoice amount
currencystringDetected currency code (USD, EUR, INR, etc.)
lineItemsarrayArray of line items with description and amounts
confidencenumberExtraction confidence score (0-100)

Error Handling

The API uses standard HTTP status codes. Errors return a JSON body with details:

// 400 — Bad Request
{
  "error": "Invalid request — body must contain \"text\" field"
}

// 401 — Unauthorized
{
  "error": "Unauthorized — invalid or missing API key"
}

// 429 — Rate Limit Exceeded
{
  "error": "Rate limit exceeded",
  "limit": 30,
  "retry_after": "60 seconds"
}

// 500 — Server Error
{
  "error": "Parse failed",
  "details": "Error message here"
}
StatusMeaning
200Success
400Bad request — invalid input
401Unauthorized — missing or invalid API key
404Route not found
413File too large (max 10MB)
429Rate limit exceeded
500Internal server error

Quick Start

Try the API with curl — no API key needed in dev mode:

curl -X POST https://invoice-parser.up.railway.app/parse \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Invoice #1234\nDate: May 15, 2024\nTotal: $500.00"
  }'

Or try it with JavaScript:

const response = await fetch('https://invoice-parser.up.railway.app/parse', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: 'INVOICE\nInvoice #: INV-2024-0087\nDate: May 15, 2024\nTotal: $7,376.92'
  })
});

const data = await response.json();
console.log(data.parsed);
// {
//   invoiceNumber: 'INV-2024-0087',
//   totalAmount: 7376.92,
//   date: '2024-05-15',
//   ...
// }

Or Python:

import requests

response = requests.post(
    'https://invoice-parser.up.railway.app/parse',
    json={'text': 'Invoice #1234\nDate: May 15, 2024\nTotal: $500.00'}
)
data = response.json()
print(data['parsed'])
